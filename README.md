# Football Analysis Lab

## 项目定位

这是一个长期建设的私人足球分析系统，目标是通过持续积累比赛数据、赔率数据、球队数据和复盘数据，建立一个不断优化的分析体系。

## 长期目标

- 自动收集足球比赛数据
- 建立球队长期画像
- 分析胜平负、进球数、比分
- 记录预测与实际结果
- 自动复盘优化模型
- 建立 10 年以上的数据资产

## 核心原则

1. 数据准确优先
2. 每次预测必须有依据
3. 所有预测必须记录和复盘
4. 模型持续优化
5. 不追求短期猜中，追求长期稳定

## 当前阶段

系统已进入自动采集与持续验证阶段。中国体彩官方场次、赔率和赛果为主数据源，并使用官方历史赛果构建免费的球队近期状态层；专业数据源可用时再补充伤停与临场首发。
